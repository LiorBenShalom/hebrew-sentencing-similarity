# Baselines for the Paper

Three complementary baselines that contextualise the main results in `../qwk/`:

1. **Random (permutation) baseline** — chance floor (advisor's GT-shuffle method)
2. **Embedding-Text** — cosine of full verdict text via OpenAI / Gemini / mE5 / BGE-M3 / Qwen3-Embedding-8B, plus BM25 (lexical)
3. **Embedding-on-rep ablation** — same 4 embedding models on each rep's structured
   features (isolates rep-structure from LLM reasoning)

> **Important — paper scope is ORDINAL similarity (3-point scale):**
> Use only the **QWK-Oracle, QWK-CV, Spearman ρ, C-index** columns from the
> CSVs. The legacy `*_REPORT.md` files (in `legacy_n11_with_binary/`) also
> contain F1 / AP columns from a binary task that is no longer in the paper.
>
> Also, those legacy reports were generated with an **earlier 11-LLM panel**.
> The current paper uses **N=13** (see `../qwk/summary_qwk_n13.csv`). The
> embedding/random baseline scores per cell are unchanged (they're per-cell,
> not per-LLM), but mean LLM-rep numbers in the legacy reports refer to the
> N=11 panel.

## Text baselines, pair-level tests (paper revision of 2026-10-10; Appendix B.6, Table B5)

| File | What |
|---|---|
| `emb_preds/embedding_{openai,gemini,e5,bge,qwen3-embedding-8b}_{drugs,weapon}_preds.csv` | Per-pair cosine scores (0–100) of the five text embedders on the gold pairs |
| `bm25_{drugs,weapon}_preds.csv` | Symmetric Okapi BM25 (k1=1.5, b=0.75) per gold pair |
| `text_baselines_spearman.csv` | Table B5: Spearman ρ of BM25 and the five embedders, with the LLM panel means for reference |
| `vs_best_embedding_cells.csv` | Every (domain, representation, LLM) cell against the best embedder on the same pairs: Steiger test for dependent correlations (one-sided), 5,000-sample pair bootstrap of Δρ, BH-FDR within domain |
| `vs_best_embedding_summary.csv` | Per (domain, representation): LLMs above the embedder, binomial / Wilcoxon-vs-constant panel tests, number of individually significant LLMs |

Reproduce (no API needed; ~3 min):

```bash
python scripts/4_similarity_analysis/text_baselines_pairlevel.py
```

The per-pair embedder scores are regenerated by `embedding_baseline.py` (OpenAI/Gemini/mE5/BGE-M3)
and `embedding_openrouter.py` (Qwen3-Embedding-8B via OpenRouter); both need API keys.

Note on `significance_vs_text_embedding.csv` (older): it tests the 13 LLM scores of a cell against the
embedder's score as a constant (one-sample Wilcoxon) on QWK/F1/AP, i.e. it asks whether the panel is
consistently above the baseline, not whether a given LLM's advantage exceeds the sampling noise of the
100/141 gold pairs. The pair-level files above answer the second question and are the ones the paper cites.

## Reproducing (with current N=13 panel + ordinal-only)

```bash
cd new_try/experiments

# Random permutation baseline (~2-3 min, 12 workers)
python3 src/analysis/random_baseline.py --n-shuffles 1000 --workers 12

# Embedding-Text baseline (~2-5 min; OpenAI API + local MPS)
python3 src/analysis/embedding_baseline.py

# Embedding-on-rep ablation (~10-15 min)
python3 src/analysis/embedding_all_reps.py
```

To regenerate with N=13 + ordinal-only output, the report scripts
(`baseline_report.py`) need to be updated to filter to QWK/Spearman/C-index
columns only. The CSVs above (`random_full.csv`, `emb_full.csv`,
`emb_reps_full.csv`) already contain the correct per-cell numbers; only the
aggregated summary tables in the legacy MD files reflect the older panel.
